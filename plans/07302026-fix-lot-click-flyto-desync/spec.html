Why

Clicking a lot runs flyTo (pan + zoom). The lot canvas only syncs on zoomanim / settle events, so tiles fly while lots freeze, then snap on moveend.

What

Keep the lot canvas geographically locked to the basemap for the full flyTo animation by applying Leaflet-style transform updates on continuous zoom frames (same idea as L.Renderer).

Assumption: pan-only motion stays on the existing CSS pane translate path (no move listener). Only continuous zoom (flyTo / pinch) needs the new handler.

Context

Relevant Files

  • src/features/map/lot-canvas.ts — canvas overlay event sync (primary fix)
  • src/features/map/MapCanvas.tsx — goToLot → flyTo (unchanged unless needed)

Patterns To Follow

  • Leaflet L.Renderer zoom + _updateTransform for flyTo frames
  • Existing _animateZoom / full-viewport canvas NW-anchor transform

Reference file: src/features/map/lot-canvas.ts — extend in place; analog is Leaflet Renderer zoom transform.

Worktree: executed in primary checkout (-i, no worktree bootstrap). Branch main @ 2d39219.

Constraints

Must

  • Lots stay aligned with tiles during lot-click flyTo
  • Settle still goes through existing _reset
  • Keep pan-only cheap (no per-frame redraw on drag pan)

Must Not

  • No new dependencies
  • Do not wrap Leaflet layers in framer-motion
  • Do not refactor MapCanvas selection UX unless required

Out Of Scope

  • Block-cluster flyToBounds polish
  • Drawer / chrome inset motion
  • Replacing flyTo with setView

Risk

Level: 2 — Concern (map interaction correctness)

Risks Identified

  • Wrong transform origin mid-flight causes drift. Mitigation: store NW + zoom at last _reset; never use live bounds as the drawn origin.
  • Redraw mid-flight while a zoom transform is active. Mitigation: selection redraw happens before flyTo; avoid adding a move redraw path.

Blast radius: all lot canvas consumers — MapCanvas lot pick, search go-to-lot, ?lot= deep link, hover/selection paint.

Pushback

  • Alternative: drop animated zoom and setView on click — simpler but loses motion. Recommended: keep flyTo and sync transforms like Leaflet’s own renderers.
