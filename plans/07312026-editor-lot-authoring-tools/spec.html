Why

Adding inventory today spans three wizard steps (Blocks → Lots → Tiers) and prices never appear, so the operator cannot see what a block is worth while creating it. And real cemeteries are messy: rows bend, singles get squeezed in, markers drift — but the editor only offers grid-level tools. Per-lot refinement (nudge, rotate, duplicate, delete) barely exists outside the buried Align mode.

What

Two upgrades that keep the existing architecture:

1. One-card block creation. Draw the boundary → the New Block card now shows each tier with its current price, auto-fits rows × cols to the drawn shape, previews the lot count and estimated value live, and one button creates the block with its lots (single undo step). "Create empty block" stays as the secondary path into the Grid tool.

2. Direct per-lot tools. With any selection: nudge in 0.05 / 0.25 / 1 m steps (buttons + arrow keys), rotate in 0.5° / 5° steps (buttons + [ ] keys), duplicate along the row direction (chain-stamp irregular rows), and delete — with sold/occupied/interred lots visibly protected: they are never deleted, never moved, and the UI says so instead of failing silently.

Context

Existing machinery this builds on (no new abstractions)

  • geometry-transform.ts — applyAlignmentTransform already translates/rotates arbitrary lot selections around a pivot; per-lot tools are one-shot wrappers.
  • lib/grid-generator.ts — fitToBlock (auto rows×cols), planGrid (boundary-clipped cells), buildLots (mints lots), isProtected (sold / occupied / contract / interments).
  • lib/price-resolver.ts — resolvePrice(book, tier, 'pre_need', 'spot_cash', today); price book from the dataset (data.prices); formatPeso.
  • BulkActionsBar.tsx — the selection bar; gains the Position cluster and duplicate.
  • Store mutate() gives every action snapshot undo; rapid nudges coalesce into one undo entry.

Reference file: src/features/map-editor/BulkActionsBar.tsx — panel/action conventions to match.

Constraints

Must

  • Protected lots (sold / occupied / contract / interments): never deleted, never moved or rotated; UI communicates the guard.
  • Every mutation is one undo step; nudge bursts coalesce.
  • Prices come from the price book resolver — never hard-coded.

Must Not

  • No new dependencies, no new panels/z-layers — extend existing surfaces.
  • No changes to publish/diff semantics or the Align mode.
  • No drive-by rework of the 6-step wizard.

Out Of Scope (recorded for the next iteration)

  • Pointer-drag moving of lots on the canvas (today: keys + nudge pad).
  • Full wizard IA redesign.
  • Duplicating with non-default gutters per tier.

Assumptions (-i self-resolved)

  • Display price = pre-need × spot-cash, today's book; null → "Contact for pricing".
  • Duplicates of sold/occupied lots are clean available copies (geometry only).
  • Auto-fill uses 0.6 / 0.9 m default gutters; fine-tuning stays in the Grid tool.

Risk

Level: 2 — touches the editor store (undo semantics) and the main selection bar.

Risks Identified

  • Keyboard arrows now act in inventory mode. Mitigation: only when a selection exists; Align-mode branch unchanged; inputs/textareas already excluded.
  • Undo-stack flooding from key repeat. Mitigation: 900 ms same-selection coalescing window.
  • One-shot create bypasses the Grid tool's exact-count/numbering options. Mitigation: it writes the block's grid params, so the Grid tool reopens exactly on them.

Blast radius: store consumers (BulkActionsBar, GridPanel, helpers.ts report/validation — untouched fields), BlockPanel, MapEditorPage keyboard, publish diff (unchanged shapes).
